A poem about agency: the agent signs in no time at all, but the pause before the hand comes down — the doubt, the choosing, the yes that knows it could be no — is the whole of the person. Written as a small Node program that prints the poem to `entry.txt`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
